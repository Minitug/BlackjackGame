# Blackjack Game

A simple Blackjack game developed in Python as part of a programming project.

The project currently focuses on the core game logic and terminal gameplay, with the possibility of adding a GUI later.

## Current Features

- Standard 52-card deck
- Card shuffling and drawing
- Hand value calculation
- Ace handling
- Hit and stand
- Bust detection
- Round-based game loop

## Planned Features

- Player balance and betting
- Surrender
- Double down
- Split hands
- Multiplayer
- GUI
- Additional testing and edge-case handling

## Project Structure

```text
blackjack_game/
├── main.py
└── blackjack/
    ├── __init__.py
    ├── cards.py
    ├── players.py
    ├── game.py
```

## Running the Game

Run the project from the repository root:

```bash
python main.py
```
